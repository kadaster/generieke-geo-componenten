Het legenda component wordt automatisch bijgewerkt als er kaartlagen in de kaartcomponent (ggc-map) zichtbaar worden of verdwijnen. De legenda laat standaard alleen legenda's zien van kaartlagen die zichtbaar zijn op het gekozen zoomniveau.

Instelmogelijkheden voor legenda:

  • Legenda's in-/uitklapbaar maken met collapsable
  • Volgorde van kaartlagen in de legenda met legendIndex
  • Melding tonen (emptyLegendMessage) bij kaartlagen zonder legenda met showEmptyLegendMessage
  • Kaartlagen altijd tonen, ook als ze niet zichtbaar zijn op de kaart, met alwaysEnableLegends
  • Eigen styling voor iconen voor in-/uitklappen

De achtergrondkaart is in dit voorbeeld vervangen door de OGC API tiles van de BRT achtergrond. De legenda is gebaseerd op de bijbehorende OGC API Style.

Let op: in de kaartconfiguratie is het noodzakelijk dat de activeLegend gevuld is. In dit voorbeeld zijn drie soorten legenda's opgenomen: een png voor de BRT achtergrondkaart, een svg voor BAG terugmeldingen en een iconList voor BGT terugmeldingen.
