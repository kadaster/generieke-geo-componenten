In dit voorbeeld is de luchtfoto als laag toegevoegd aan de 3D kaart. Deze kaartlaag wordt als meerdere afbeeldingen (bijv. PNG, JPEG, ...) door ggc-map opgevraagd bij een Web Map Tile Service. Een WMTS kaarlaag kan in een 3D kaart bijvoorbeeld gebruikt worden als achtergrondkaart. De kaartlaag wordt over het digitale terreinmodel (DTM) gelegd, zodat het hoogteverschil van het landschap zichtbaar wordt.
