In dit voorbeeld zijn 2 geojson lagen toegevoegd bovenop de achtergrondkaart. De rode lijnen zijn de gemeentelijnen, waarbij de rode kleur is toegevoegd in de configuratie. De roze labels zijn BAG terugmeldingen, waarbij ook de style is ingesteld in de configuratie. De BGT meldingen zijn de rode pins. Deze rode pins is een SVG afbeelding die is ingeladen via de geoJsonConfig die gekoppeld is via het layerId. Deze entitiesFunction kan uiteraard worden uitgebreid met extra logica waardoor verschillende SVGs gekoppeld kunnen worden aan specifieke properties van het object.
