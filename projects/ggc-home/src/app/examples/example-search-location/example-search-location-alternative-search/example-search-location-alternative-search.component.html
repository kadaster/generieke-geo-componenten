In dit voorbeeld kan je naast de PDOK Locatie API ook zoeken in een eigen collectie, die de BAG terugmeldingnummers bevat. Door te zoeken op "BAG..." met een meldingsnummer erachter, krijg je resultaten van de terugmeldingen die overeenkomen met het opgegeven meldingsnummer.
Om een eigen collectie te gebruiken, moet je het volgende doen:

  1. Maak een eigen service aan die de search functie implementeerd, zie hiervoor GgcAdditionalSuggestionSourceService. Wij hebben hiervoor een AlternativeSuggestService gemaakt.
  2. Provide deze service als GgcAdditionalSuggestionSourceService
  3. Vang SearchComponentEvents af om resultaten van je eigen collectie te behandelen. In dit geval zoomen wij in naar het coordinaat van de gezochte melding.
