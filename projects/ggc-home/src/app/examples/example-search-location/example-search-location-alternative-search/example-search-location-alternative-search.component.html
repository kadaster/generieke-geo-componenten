In dit voorbeeld kan je ook zoeken in een eigen collectie naast de PDOK Locatie API , namelijk de BAG terugmeldingnummers. Door te zoeken op "BAG" met een (deel van het) meldingsnummer erachter, kan je zoeken naar terugmeldingen met het opgegeven meldingsnummer.
Een eigen collectie gebruiken kan als volgt:

  1. Maak een eigen service aan die de search functie implementeerd, zie hiervoor GgcAdditionalSuggestionSourceService. Wij hebben hiervoor een AlternativeSuggestService gemaakt.
  2. Provide deze service als GgcAdditionalSuggestionSourceService.
  3. Vang SearchComponentEvents af om resultaten van je eigen collectie te behandelen. In dit geval zoomen wij in naar het coördinaat van de gezochte melding. Er wordt automatisch in de PDOK resultaten gezocht, dus deze hoef je niet af te vangen.
