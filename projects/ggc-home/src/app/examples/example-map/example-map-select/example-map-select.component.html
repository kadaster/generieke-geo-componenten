GGC beidt ondersteuning voor selecties op alle kaartlagen, maar wij raden aan om WFS of OGC kaartlagen te gebruiken, gezien dit makkelijker werkt. Mocht je WMS of WMTS kaartlagen willen gebruiken, bekijk dan het voorbeeld over selecties op WMS/WMTS lagen, gezien dit minder mogelijkheden biedt.

Voor WFS en OGC kaartlagen zijn verschillende selectie methodes:

  • Single select: door te klikken kan je één feature selecteren.
  • Multi select: je kan meerdere features selecteren en een feature uit de selectie halen door op een geselecteerde feature te klikken.
  • OpenLayers default: met een normale klik wordt één feature geselecteerd en met een shift‑klik kan een multi‑selectie worden gedaan.
  • Hover: een single select die met het instellen van de condition nu werkt met de muis-hover in plaats van klikken.
