Met het ggc-map component kan op ieder type kaartlaag een object geselecteerd worden. Selecteren van objecten werkt het beste met WFS en OGC API kaartlagen.

Dit voorbeeld bevat de selectiemethoden voor WFS, deze zijn ook beschikbaar voor OGC API Features en OGC API Tiles:

Instelmogelijkheden voor de selectService:

  • Single select: selecteer één object door te klikken in de kaart.
  • Multi select:
    • selecteer meerdere objecten door te klikken in de kaart.
    • verwijder een object uit de selectie door op een geselecteerd object te klikken.
  • OpenLayers default:
    • selecteer één object door te klikken in de kaart.
    • selecteer meerdere objecten door shift ingedrukt te houden en te klikken in de kaart.
  • Hover: selecteer één object door de muis over de kaart te bewegen (dit werkt hetzelfde als single select, zonder te klikken op de kaart).
