Dit is mogelijk voor WMTS- ,WMS-, GeoJSON-kaart(en) en OGC API vector Tiles.

Dit voorbeeld toont de grenzen van gemeenten. Na het kiezen van een gemeente zie je de aangepaste informatie.

Instelmogelijkheden voor de featureInfoConfigService:

  • attributeOrder: volgorde van de attributen instellen.
  • hideUnorderedAttributes: verbergen van velden. Alleen de attributen die zijn meegegenen in atributeOrder worden getoond (in dit voorbeeld 'naam', 'code', en 'ligtInProvincieNaam').

Instelmogelijkheden voor customFeatureInfo:

  • customAttributeName: aanpassen van namen van attribuutvelden. In dit voorbeeld:
    • code => gemeente code
    • ligtInProvincieNaam => ligt in
  • customAttributeValueFunction: aanpassen van waarden van attribuutvelden. In dit voorbeeld:
    • naam => gemeente + naam
    • code => GM + code

Mocht je ook de HTML van de feature info component willen veranderen, dan kan je ook het voorbeeld Objectinformatie weergeven met eigen templates bekijken.

Toon alleen de velden 'naam', 'code' en 'ligtInProvincieNaam'
