Wij raden aan om objecten te selecteren op WFS of OGC API kaartlagen in plaats van WMS/WMTS kaartlagen. Deze bieden meer mogelijkheden en zijn makkelijker in te richten. Bekijk dit voorbeeld over selectiemogelijkheden met een WFS of OGC API kaartlaag.

Selectie op een WMS of WMTS kaartlaag werkt anders dan een GeoJSON of een vector kaartlaag, omdat de objecten niet in de front-end zijn opgeslagen. De juiste configuratie is daarom belangrijk bij selectie op WMS/WMTS kaartlagen:

  • Zet de property getFeatureInfoOnSingleclick op "true" voor WMS of WMTS kaartlagen die gebruikers mogen selecteren.
  • Gebruik op single en multi select altijd de default condition singleclick.
  • Een object kan alleen op de kaart weergegeven worden als de WMS of WMTS de geometry aanlevert in de feature info

De SelectionService werkt voor WMS en WMTS op dezelfde manier als andere kaartlaag types. Ze kunnen ook tegelijkertijd met andere kaartlaag types gebruikt worden. Ook kunnen selecties gestart worden met LayerIds.
