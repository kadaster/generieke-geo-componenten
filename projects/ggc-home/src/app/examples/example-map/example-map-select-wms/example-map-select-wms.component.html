Wij raden aan om bij selecties WFS of OGC kaartlagen te gebruiken in plaats van WMS/WMTS kaartlagen, gezien dit meer mogelijkheden biedt en makkelijker werkt. Zie hiervoor het andere selectie voorbeeld.

Een selectie op een WMS of WMTS kaartlaag wordt wel ondersteunt, maar werkt anders dan een geojson of een vector kaartlaag, omdat de features niet in de front-end zijn opgeslagen. Er is wel ondersteuning voor WMS en WMTS kaartlagen, maar deze moeten wel goed geconfigureerd worden:

  • De property getFeatureInfoOnSingleclick moet op true worden gezet voor WMS of WMTS kaartlagen die geselecteerd moeten kunnen worden.
  • Selecties op WMS of WTMS kaartlagen werken alleen met singleclick op een single en multi select modus.
  • De feature info van de WMS/WMTS moet ook een geometry teruggeven, anders kan de feature niet worden weergegeven.

Verder werken WMS en WMTS kaartlagen hetzelfde en kunnen op dezelfde manier (en ook tegelijkertijd) gebruikt worden in de SelectionService met andere kaartlagen. Ook de optie LayerIds voor het starten van een selectie werkt met de WMS/WMTS kaartlagen.
