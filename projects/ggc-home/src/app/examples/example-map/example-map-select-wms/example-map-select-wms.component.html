Wij raden aan om objecten te selecteren op WFS of OGC API kaartlagen in plaats van WMS/WMTS kaartlagen. Deze bieden meer mogelijkheden en zijn makkelijker in te richten. Bekijk dit voorbeeld over selectiemogelijkheden met een WFS of OGC API kaartlaag.

Voor WMS en WMTS worden de volgende selectiemethodes ondersteund:

  • Single select: selecteer één object door te klikken in de kaart.
  • Multi select:
    • selecteer meerdere objecten door te klikken in de kaart.
    • verwijder een object uit de selectie door op een geselecteerd object te klikken.

Bij WMS/WMTS kaartlagen wordt objectinformatie niet door de browser opgeslagen. Bij klikken op de kaart wordt de objectinformatie van de betreffende locatie opgehaald. Hiervoor is het belangrijk om op het volgende te letten:

  • Zet de property getFeatureInfoOnSingleclick op "true" voor kaartlagen die gebruikers mogen selecteren (dit geldt voor alle type kaartlagen).
  • Gebruik op single en multi select altijd de default condition singleclick.
  • Om het object weer te kunnen geven, moet de feature info(*) van de WMS/WMTS een geometry teruggeven.

De SelectionService werkt voor WMS en WMTS op dezelfde manier als andere kaartlaag types. Ze kunnen tegelijkertijd met andere kaartlaag types gebruikt worden. Ook kunnen selecties gestart worden met LayerIds.

(*) Dit is de feature info van de Web Map Service (WMS) of Web Map Tile Service (WMTS).
