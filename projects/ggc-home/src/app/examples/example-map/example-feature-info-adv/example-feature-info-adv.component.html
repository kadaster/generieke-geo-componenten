Dit is mogelijk voor WMTS- ,WMS-, GeoJSON-kaart(en) en OGC API vector Tiles.
Dit voorbeeld toont de grenzen van gemeenten. Na klikken in de kaart wordt de informatie opgehaald van de kaartlaag. De informatie van het gekozen object wordt getoond en het object wordt op de kaart gemarkeerd.

Instelmogelijkheden voor het tonen van objectinformatie:

  • Toon melding "Geen informatie beschikbaar" als geen gemeente is geselecteerd (showEmptyMessage)
  • Verberg "1 van 1" als maar één object geselecteerd is (hidePagerWithOneFeature). Deze wijziging wordt pas actief nadat een nieuwe selectie is gedaan.
  • Wisselen tussen lijst- of tabelweergave (FeatureInfoDisplayType)
  • Highlight stijl veranderen (changeHighlightLayerStyle)
