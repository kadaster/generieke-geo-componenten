Op basis van een ng-template is het mogelijk om eigen HTML te gebruiken voor velden in de het feature-info component. In dit voorbeeld kan je klikken op de BAG panden voor informatie. Via de ggcTemplateKey en het templateType is in te stellen welk gedrag je wilt veranderen met de HTML templates. In dit voorbeeld hebben wij het onderstaande toegepast:

  • CONTENT: Hiermee kan je de de HTML van de waarde aanpassen. In dit voorbeeld wordt het rdf-seealso veld weergegeven als een url.
  • HEADER: Hiermee kan je de naam/header aanpassen. In dit voorbeeld hebben wij de naam "aantal_verblijfsobjecten" veranderd naar "aantal verblijfsobjecten".
  • HIDE: Hiermee kan je velden verborgen maken, maar nog wel gebruiken in andere feature-info velden. In dit voorbeeld hebben wij external_fid verborgen.
  • HIDE_IF_EMPTY: Hiermee kan je velden verborgen maken als deze leeg zijn. In dit voorbeeld hebben wij bouwjaar verborgen als deze leeg is.
