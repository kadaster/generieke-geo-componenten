In dit voorbeeld zie je de BAG panden. Na het kiezen van een pand zie je de aangepaste informatie.

Op basis van een ng-template is het mogelijk om eigen HTML te gebruiken voor velden in de feature-info component. Via de ggcTemplateKey en het templateType is in te stellen welk gedrag je wilt veranderen met de HTML templates.

Instelmogelijkheden met ng-templates:

  • CONTENT: Aanpassen van de de HTML (waarde). In dit voorbeeld wordt het rdf-seealso veld weergegeven als een url.
  • HEADER: Aanpassen van de HTML (naam/header). In dit voorbeeld wordt de naam "aantal_verblijfsobjecten" veranderd naar "aantal verblijfsobjecten".
  • HIDE: Hiermee kan je velden verborgen maken, maar nog wel gebruiken in andere feature-info velden. In dit voorbeeld wordt external_fid verborgen.
  • HIDE_IF_EMPTY: Hiermee kan je velden verborgen maken als deze leeg zijn. In dit voorbeeld wordt bouwjaar verborgen als deze leeg is.

Mocht je alleen de waardes van de feature info component willen veranderen, zonder HTML wijzigingen, dan kan je ook dit voorbeeld bekijken.
