Dit voorbeeld toont FeatureInfo met de informatie geordend in tabbladen per kaartlaag. Hiervoor wordt het FeatureInfoTabs component gebruikt. Informatie wordt opgehaald door middel van een klik in de kaart voor lagen waarvoor dit is ingesteld (getFeatureInfoOnSingleClick). De titel van een kaartlaag wordt gebruikt als label op de tab bladen. Het actieve feature wordt getoond in de kaart. De volgorde van de tabbladen kan worden gewisseld, dit werkt echter pas na een nieuwe klik in de kaart.
