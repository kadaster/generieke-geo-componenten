Dit voorbeeld toont FeatureInfo met de informatie geordend in tabbladen per kaartlaag. Hiervoor wordt het FeatureInfoTabs component gebruikt. Informatie wordt opgehaald door middel van een klik in de kaart voor lagen waarvoor dit is ingesteld (getFeatureInfoOnSingleClick). De titel van een kaartlaag wordt gebruikt als label op de tab bladen. Het actieve feature wordt getoond in de kaart. In de rechter kolom kun je verschillende opties instellen die invloed hebben op hoe de feature info wordt weergegeven. Let wel de opties voor het tonen van paginering en het wisselen van tabvolgorde werken pas na een nieuwe klik in de kaart.
