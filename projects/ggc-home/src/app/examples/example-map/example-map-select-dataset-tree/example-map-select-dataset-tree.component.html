Wij raden aan om objecten te selecteren op WFS of OGC API kaartlagen in plaats van WMS/WMTS kaartlagen. Deze bieden meer mogelijkheden en zijn makkelijker in te richten. Bekijk dit voorbeeld over selectiemogelijkheden met een WFS of OGC API kaartlaag.

Dit voorbeeld bevat de selectiemethoden voor WFS, OGC API, WMS en WMTS kaartlagen:

  • Single select: selecteer één object door te klikken in de kaart.
  • Multi select:
    • selecteer meerdere objecten door te klikken in de kaart.
    • verwijder een object uit de selectie door op een geselecteerd object te klikken.

Let op: bij het uitzetten van een kaartlaag wordt de huidige selectie automatisch volledig verwijderd. Voor de BGT standaardvisualisatie en BAG (vector tiles) moet eerst worden ingezoomd totdat de kaartlagen zichtbaar zijn.
