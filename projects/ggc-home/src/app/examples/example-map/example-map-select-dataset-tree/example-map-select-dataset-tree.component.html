Dit voorbeeld laat het effect zien van selectie op meerdere kaartlagen. Voor de BGT standaardvisualisatie en BAG (vector tiles) moet eerst worden ingezoomd totdat deze kaartlagen zichtbaar zijn.

Voor WFS, OGC API, WMS en WMTS worden de volgende selectiemethodes ondersteund:

  • Single select: selecteer één object door te klikken in de kaart.
  • Multi select:
    • selecteer meerdere objecten door te klikken in de kaart.
    • verwijder een object uit de selectie door op een geselecteerd object te klikken.

Bij het uitzetten van een kaartlaag wordt de volledige selectie van alle kaartlagen automatisch gewist.

Let op: Wij raden aan om objecten te selecteren op WFS of OGC API kaartlagen in plaats van WMS/WMTS kaartlagen. Deze bieden meer mogelijkheden en zijn makkelijker in te richten. Bekijk dit voorbeeld over selectiemogelijkheden met een WFS of OGC API kaartlaag.
