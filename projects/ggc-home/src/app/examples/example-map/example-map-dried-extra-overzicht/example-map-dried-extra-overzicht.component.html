In dit voorbeeld is een overzichtskaart toegevoegd aan de 3D kaart. In de overzichtskaart geeft het blauwe kader aan welk gebied op de hoofdkaart zichtbaar is. Zo kan de gebruiker in één oogopslag zien waar hij zich bevindt in het grotere geheel. Wanneer er in de 3D hoofdkaart wordt geschoven of gezoomd, wordt de overzichtskaart automatisch bijgewerkt.

De overzichtskaart heeft een eigen mapIndex. Hierdoor kan de overzichtskaart onafhankelijk van de 3D hoofdkaart worden geconfigureerd. De 3D-hoofdkaart wordt apart aangestuurd via de Cesium viewer- en cameraservices.
