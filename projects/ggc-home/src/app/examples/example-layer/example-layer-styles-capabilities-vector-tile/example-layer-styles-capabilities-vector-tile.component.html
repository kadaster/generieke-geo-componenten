In dit voorbeeld staat bij de vector tile kaartlaag alleen requestCapabilities op true; er zijn geen styles en geen activeStyle in de kaartconfiguratie opgenomen. Bij het laden van de kaartlaag worden de styles uit de OGC API van de service gehaald. De eerste style uit de capabilities wordt de actieve style.

De legenda wordt opgebouwd uit de mapbox stylesheet die de OGC API bij elke style levert. Alleen styles in het Rijksdriehoekstelsel (EPSG:28992) worden meegenomen.

Uit de capabilities volgt ook op welke zoomniveaus de service tiles aanbiedt. Zoom je verder uit dan dat bereik, dan verdwijnen de kaartlaag en de bijbehorende legenda automatisch — zonder requestCapabilities had je daarvoor zelf minResolution en maxResolution moeten instellen.
