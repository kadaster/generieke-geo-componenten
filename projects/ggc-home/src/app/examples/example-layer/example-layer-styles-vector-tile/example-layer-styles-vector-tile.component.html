Sommige kaartlagen hebben styles die kunnen worden gebruikt om de weergave van een kaartlaag aan te passen. Als er een legenda is ingesteld bij een style, dan zal ook deze automatisch geupdatet worden als een style verandert. Binnen de kaartlaag kunnen de beschikbare styles worden geconfigureerd:

  • styles: hierin staan alle beschikbare styles.
  • activeStyle: De naam van de style die actief is. Mocht er geen actieve style zijn ingesteld, dan wordt de eerste style in styles getoond.
