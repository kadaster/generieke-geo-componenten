## GGC Print

Dit project levert frontend componenten voor het selecteren van een af te drukken gebied en het kiezen van een print-template. Dit project kan alleen gebruikt worden met een [MapFish Print 3 server](https://github.com/mapfish/mapfish-print/tree/3.33.0). **Let op:** de documentatie en voorbeelden voor GGC Print zijn nog in ontwikkeling.
